# 📖 Project Overview

StudyNook is a modern and responsive study room booking platform designed for students, researchers, and library users who need a simple way to discover and reserve quiet study spaces. The platform allows users to browse available rooms, view room details, search and filter rooms based on amenities, and reserve time slots without scheduling conflicts.

Users can also create and manage their own study room listings through a personalized dashboard. The application includes secure authentication using Better Auth, JWT, and HTTP-only cookies to ensure protected private routes and persistent login sessions. StudyNook focuses on clean UI design, responsive performance, scalability, and smooth user experience across all devices.
